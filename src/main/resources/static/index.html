URL Shortener

Prototype

A small manual test console for the API — shorten a link, resolve it, and check its stats.

Shorten a URL

Enter a long http or https URL to get its short code and short URL.

Optional. Leave blank for a link that never expires.

Go to the original URL

Enter a short code (e.g. aB3xY9z) or a short URL (e.g. http://localhost:8080/aB3xY9z). Navigates you to the target after a moment — this counts as a click.

View analytics

Enter a short code (e.g. aB3xY9z) or a short URL to see its click stats. Does not count as a click.
